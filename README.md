# MA Sorteio de Times

Sorteio de times equilibrados pra pelada, sem anúncio. Primeira pelada de teste: **Bola Fora**.

## Rodar no computador

```bash
npm install
npm run dev
```

Abra http://localhost:3000 e vá em **Montar sorteio**.

## Documentação

- `PROJETO.md`: mapa completo (telas, regras, banco, etapas).
- `supabase/schema.sql`: banco de dados da etapa 2.
