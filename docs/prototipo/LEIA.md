# Protótipo das telas

Cópia das telas do protótipo do MA Sorteio de Times (versão de 24/11/2026). Versão clicável online: https://claude.ai/artifact/RNQsAVNEBKM9caUbSS8Ma5

Cada `.dc.html` é uma tela de celular (390×844) com estilo inline. O bloco `<script type="text/x-dc">` no fim de cada arquivo tem os dados de exemplo e o comportamento (o que acontece ao tocar). `{{ algo }}` = valor calculado no script; `<sc-for>` = repetição; `<sc-if>` = mostra só se. São referência visual, não código pra copiar direto.

| Arquivo | Tela |
|---|---|
| Main | Início |
| ColarLista | Colar lista do WhatsApp |
| Jogadores | Elenco e avaliação |
| Sorteio | Montar sorteio |
| Times | Times sorteados |
| Partida | Partida (junta com AoVivo numa tela só) |
| AoVivo | Link público ao vivo |
| Resultados | Resultados do dia |
| FimPelada | Fim da pelada, prêmios, mensagem pro Zap |
| Banners | Banners de premiação |
| Votacao | Craque e bagre |
| Campeonato | Campeonato e goleiros |
| CardJogador / Carta | Card do jogador e raridades |
| Album | Álbum e seleção do mês |
| Feedback | Avaliação pós-jogo |
| Mais | Presença, mensalidade, nota da pelada, atalhos |
| Entrar | Login e instalar |
| Master | Painel master |
